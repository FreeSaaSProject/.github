# FreeSaaS

**Open-source business operating system designed to be installed and operated by AI agents.**

Modular PHP platform: CRM, shifts, finance, booking, banks, warehouse, audio analytics, and more as filesystem modules. Agents install, configure, verify, and extend the system via CLI, `/agent/*`, and MCP — without browser automation.

- **Website:** [freesaas.ru](https://freesaas.ru) ([English](https://freesaas.ru/en/))
- **Code:** [FreeSaaSProject/freesaas](https://github.com/FreeSaaSProject/freesaas) (AGPL-3.0-or-later · optional [commercial license](https://github.com/FreeSaaSProject/freesaas/blob/main/COMMERCIAL-LICENSE.md))
- **Live demo:** [demoru.freesaas.ru](https://demoru.freesaas.ru) (RU) · [demoen.freesaas.ru](https://demoen.freesaas.ru) (EN) — signed in, read-only, data resets regularly

## Principles

- **Open source** — AGPL-3.0-or-later; commercial license available when AGPL is not a fit.
- **Local first** — runs on your own server or laptop; no mandatory cloud for core ops.
- **Own your data** — MySQL/`base_*` tables, open formats, self-hosted updates.
- **Agent-native** — install and operate via CLI / `/agent/*` / MCP, not only a browser UI.
- **Commodity hardware** — shared hosting and Docker-friendly; requirements documented per release.
